🅰️ OpenAI｜GPT-6 Astra 登場，先過政府與網安這道關

  • 2026-09-03 GPT-6 Astra：OpenAI 稱「世上最強 computer-use 模型」，亦為首個被官方列為「Critical 風險等級」的模型；OSWorld 2.0 衝上 72.6%（每任務約 40 分鐘，比 Sol 快近一半）、DeepSWE v1.1 74.1%、ExploitBench 100%。
  • 資安門控（Daybreak）：Astra 最強的網安攻防能力採認證制，第一天先給 Daybreak 網安計畫企業；付費用戶 / API / AWS Bedrock / Azure 數日後陸續放出。免費版與 API Free tier 完全不支援。
  • 新架構「recurrent depth」爭議：採用迴圈式 transformer（looped transformer）提升效率，但也「遮蔽部分思考鏈」（chain of thought），引發 AI 安全專家疑慮——我們看到更強的任務完成度，卻看不到它為何這樣想。
  • 2026-07-08 GPT-5.6 Sol／Terra／Luna：原本僅限少數信賴夥伴，約兩週後才全球公開；8 月起 Luna 成為免費版預設。
  • 公司戰報：ChatGPT 2026-06 突破 10 億月活；Codex 週活 500 萬；06-08 遞交 S-1，目標估值 $830B–$1T。
📌 免費課金點：強模型全往付費端收——Astra 只給 Plus 以上、API Free tier 直接無緣；最新模型發布前先請政府目測（30 天自願預審），免費版拿到手時往往已是「半舊旗艦」。

🅱️ Anthropic｜Fable 5.1 倍數級進化，卻捲入音樂版權戰

  • 2026-09-01 Fable 5.1／Mythos 5.1：官方稱「世上最強 coding 與知識工作模型」；Terminal-Bench-Science 分數 24.7 → 52.6（自報，尚待獨立複測）；API 照舊 $10/$50，快取讀取降到 $0.25。
  • Mythos 5.1 是「可信存取 twin」：僅授權客戶可用，強制 30 天資料保留——高風險能力愈鎖愈緊。
  • 爭議08-31 音樂版權訴訟：Sony Music 與 Warner Chappell 於加州聯邦法院提告，指控 Anthropic 透過 BT 下載等「公然盜版」方式取得數萬首歌詞與樂譜訓練 Claude；求償每件最高 $150,000，CEO Dario Amodei 與合夥人 Benjamin Mann 被點名。Anthropic 回應「這是重複提告，將強力抗辯」。
  • 前案脈絡：去年因作者集體訴訟（Bartz 案）被判賠 $15 億；法官認為「用版權資料訓練」合法，但「以盜版方式取得」不合法——此案把戰火從「取得」燒到「輸出」端。
  • 9/14 里程碑：Claude Code 週用量上限將較目前下修 17%（回到 5 月前水準的 +25%）。
📌 免費課金點：免費方案永遠拿「Sonnet 級」；Fable／Mythos／Opus 高階全部僅限付費。版權官司懸而未決，商用開源前「法務永遠比工程師先動手」。

🅳 xAI｜Grok 4.6 扛旗，Grok 5 還在練功

  • 2026-08-12 Grok 4.6：Opus 級旗艦，500K 上下文，專攻 coding 與 agentic；API $2/$6（cached 輸入 $0.50）——對標高階但明顯更便宜。
  • 性價比焦點：媒體引 xAI 數據稱 Grok Build 完成一次 coding task 約 $2.49，等同任務在 Claude Fable 5 環境約 $11.80——號稱省 80%，但換來較高的幻覺率。
  • 2026-07-16 Grok 4.5：「編碼、Agent、知識工作」主力，可在 API 調整推理努力（低／中／高）。
  • Grok 5 傳聞：目標 ~6 兆參數 MoE、1.5M 上下文、原生多模態；截至 9 月仍在訓練（馬斯克暗示 Grok 4.7 視窗，但尚無 model id）。
📌 免費課金點：Grok 4.5／4.6 與 Grok Bot 都要 SuperGrok 或 X Premium+；免費版只能摸舊版 Grok，額度低、得忍受推廣位。

🅴 Meta／開源陣營｜訓練資料歷史性開源，開源定義被重新點燃

  • 重磅09-03 K2 Horizon（IFM／MBZUAI）：阿布達比研究機構一次釋出六個模型（0.9B～375B），權重＋程式碼＋訓練資料＋checkpoint＋日誌全公開（Apache 2.0）——被譽為 2026 年首度真正符合「開源」定義的發布。訓練資料正是各家死守、唯獨它願意給的關鍵。
  • Meta：Llama 4 仍是開源主力；04-08 Muse Spark 成首個封閉權重前沿模型，9/2 出 1.3；08-10 Muse Glimmer（30B 稠密多模態、Apache 2.0、128K）單張消費級 GPU 可跑——「封閉與開源雙面下注」。
  • DeepSeek：07-31 V4-Flash-0731 正式版 $0.14/$0.28 超低定價，Terminal-Bench 2.1 61.8 → 82.7。
  • Qwen 最勤勞：3.5 → 3.6 → 3.8 連發；08-26 Qwen3.8-Flash-Next 預覽 Qwen4 架構——125B 總參數僅 6B active，且 51B 元件設計跑在系統 RAM（省 GPU 記憶體）。旗艦 Gradio 權重也開（2.4T）。
  • 警訊「開源權重」正在變質：今夏多次釋出不再用 Apache——Qwen3.8-Max 用自有授權、Kimi K3 用改良 MIT、GLM-5.3 授權未明；Open Source Initiative 直言「權重檔無法審計，MIT/Apache 是寫給可讀的原始碼」。
📌 免費課金點：開源陣營最佛——但「下載得到」不等於「免費商用」；現在連授權都開始分化。真免費成本在硬體與技術，商用前法務必審一遍。

🧭 全球監管進入「執法期」

  • EU AI Act：8/2 高風險系統過渡期結束，9 月起歐盟 AI 辦公室展開首波實地稽核（HR 履歷篩選、信用評估、醫療分流）；9/15 前超大 GPAI 模型需交首份關鍵風險評估。
  • 美國：無聯邦法，加州 SB 1047 州長 9/30 前決定簽署或否決；9/3 通過 Adam's Law（強化青少年聊天機器人安全測試）待簽。
  • 巴西：9/16 參議院就 Bill 2338 終表決（仿 EU AI Act）；印度 9/21 起審議 Digital India Act 生成式 AI 責任條款。
  • 趨勢：「先內測、再政商、後公開」成標配；開源因結構可審計反而成為監管爭議中心。

🐵 大聖點評（一線之隔的領悟）

  • 免費午餐正在縮水：2026 的免費版等於「舊旗艦體驗卡」——新版一律先鎖付費、再鎖政商專屬；連 API Free tier 都被 Astra 拔掉。
  • 「開源」二字正在被考驗：各家只放權重、不放資料，OSI 直言無法審計；直到 K2 Horizon 把訓練資料與日誌全攤開，才有人真正交卷。免費背後的代價不是錢，是看得見與看不見。
  • 法律戰火燒向訓練資料：Sony／Warner 一狀把 Anthropic 拖進億元訴訟，AI 訓練的「資料來源」成為下一個未解題——取得方式與授權，比模型本身更致命。
  • 教育界第一個大迴轉：NYC 禁 AI 家教、限螢幕時間，是美國最大學區對「AI 進校園」的正面回應——科技巨頭口中的「不可避免」，未必是所有人的答案。
  • 給你的實用提醒：老規矩——動嘴之前先看日期，新聞標題會騙人；商用開源模型，法務永遠比工程師先動手。
